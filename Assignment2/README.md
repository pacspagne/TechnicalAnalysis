## What this is

The first of a three-stage project. This stage sets up a portfolio of stock
symbols, imports their historical price data in R via the `quantmod`
package, computes basic descriptive/technical statistics (moving average,
mean, median, mode, standard deviation), and displays the results as tables
and charts.

## Repository / folder structure

```
Assignment2/
  portfolio.txt                        # 5 tracked stock symbols
  data/                                 # per-symbol OHLCV CSVs (quantmod "csv" source)
    AAPL.csv, MSFT.csv, GOOGL.csv, AMZN.csv, JPM.csv
  scripts/
    load_stock_data.R                  # load_stock_data()
    calculate_statistics.R             # calculate_statistics(), calc_mode()
    display_output.R                   # display_*() and plot_*() utilities
  output/                              # generated statistics + charts (regenerated by the scripts)
  TechnicalAnalysis_Assignment2.Rmd    # full, knitted R Markdown report
  TechnicalAnalysis_Assignment2.html   # knitted output of the .Rmd (open in any browser)
  Nnaemeka_BDA400_A02_Report.docx      # assignment report (cover page, walkthrough, screenshots)
```

## How to run it

```r
source("scripts/load_stock_data.R")
source("scripts/calculate_statistics.R")
source("scripts/display_output.R")

stocks <- load_stock_data(portfolio_file = "portfolio.txt", data_dir = "data", src = "csv")
```

Or knit the full report:

```r
rmarkdown::render("TechnicalAnalysis_Assignment2.Rmd")
```

On a normal PC with internet access, `load_stock_data(..., src = "yahoo")`
pulls live prices directly from Yahoo Finance instead of the bundled CSVs --
see the "Data source note" in the AI Assistance Declaration below and in the
Word report.

- **Data source note:** the development/verification sandbox used to build
  this project has no outbound network access to `finance.yahoo.com`, so
  `quantmod::getSymbols(src = "yahoo")` could not be executed end-to-end

  "S&P 500 stock data" dataset and loaded through the same `getSymbols()`

  quantmod usage rather than a workaround. The identical function works
  unmodified with `src = "yahoo"` on a machine with normal internet access.
